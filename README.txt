INSANE_OPSS BANNER UPDATE V2

This patch replaces the Premium and Free Sensi artwork with unique v2 filenames to avoid stale CDN/browser cache.

Extract this ZIP into the ROOT of the existing ~/Insane_opss repository, overwriting the listed files.
Then run:
  git status
  git add .
  git commit -m "Update Premium and Free Sensi banners v2"
  git push origin main

Do NOT run git init and do NOT push to master.
After push, confirm the Vercel deployment uses the new commit.
